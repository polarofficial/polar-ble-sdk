# Polar Vantage V2 watch

Multisport watch.
[Store page](https://www.polar.com/en/vantage/v2)

## Polar Vantage V2 features available by the SDK

Data export
* Activity data
* Sleep data
* Training session data

Device management
* Get/set time
* [Firmware update](../FirmwareUpdate.md)

> [!NOTE]
> Polar Vantage V2 does not provide online sensor streaming (heart rate, accelerometer etc.) via the SDK; SDK access on this product is limited to the file-based data export and the device management features listed above.
